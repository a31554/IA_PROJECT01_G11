# IA26_P01_G11

## Projeto 01 — Agente inteligente de rotas para distribuição de produtos locais

Este repositório contém os ficheiros relativos ao Projeto 01 da unidade curricular,
realizado pelo grupo **G11**.

O projeto aborda o desenvolvimento de um agente inteligente capaz de planear
rotas para a distribuição de produtos locais, tendo em conta os pedidos, as
janelas temporais, a capacidade dos veículos e a localização das paragens.

## Conteúdo da entrega

- **`EDA.ipynb`** — notebook de análise exploratória dos dados (EDA).
  Inclui a análise da organização, consistência e qualidade dos dados, dos
  pedidos e respetivas janelas temporais, da capacidade dos veículos e da
  localização das paragens.
- **`Proj01.ipynb`** — notebook principal do projeto, com o
  desenvolvimento do agente e as secções solicitadas no Guia do Projeto.
- **`README.md`** — informação sobre o projeto e ligação para o repositório.

## Como executar

1. Abrir o repositório no GitHub ou descarregar os seus ficheiros.
2. Abrir os notebooks com Jupyter Notebook, JupyterLab ou Google Colab.
3. Executar primeiro o notebook `EDA.ipynb` para consultar a análise
   exploratória dos dados.
4. Executar o notebook `Proj01.ipynb` pela ordem apresentada.

Caso sejam necessários ficheiros adicionais para a execução, estes devem ser
mantidos na mesma pasta dos notebooks, preservando a estrutura do repositório.
